# 风险与待决问题

> 状态：Draft · 更新：2026-11-03

## 风险

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | Anthropic API 变化快（beta 头、模型行为、保留思考规则） | 循环/缓存策略失效 | Provider 层隔离；每周真网冒烟；`12-model-providers.md` 维护"当前做法"表 |
| R2 | 提示缓存命中率在真实使用中低于预期（工具表/前缀频繁变化） | 成本上升 | 回合边界批量应用变化；工具搜索；控制台缓存诊断 |
| R3 | 进程外插件的内存开销在小 VPS 上过高 | 可运行插件数受限 | Python/Go 插件更省；允许把多个内置来源合并进一个进程（"插件组"） |
| R4 | 抢占语义在真实模型行为下产生混乱（被打断后模型不知所措） | 体验差 | `internal` 事件明确告知；人格 OPERATING 给出处理被打断的指引；回放评测 |
| R5 | 交接笔记质量不足导致长期一致性差 | 助理"失忆" | 评测集；允许人格自定义；INDEX.md 约束 |
| R6 | 提示注入通过 MCP 工具结果触发副作用 | 安全 | 默认 `ask`、出站白名单、origin 标注、审计 |
| R7 | SQLite 单写者在高事件量下成为瓶颈 | 延迟 | 个人场景事件量小；批量写入；必要时事件入库走 worker |
| R8 | 单镜像体积与基础镜像漏洞 | 运维 | slim 变体；定期重建；扫描 |
| R9 | 一人项目范围过大 | 延期 | 里程碑验收驱动；M7 可无限期推迟 |
