# Protea 🌿

AI-powered personal productivity platform

## 简介

Protea 是一个 AI 驱动的个人生产力平台，帮助您更好地管理任务、项目和人际关系。

## 特性

- 🤖 AI 智能任务管理
- 📱 跨平台移动端应用
- 🔒 隐私优先的本地 AI 模型
- ☁️ 可选云端同步

## 技术栈

- 后端：Node.js + NestJS + TypeScript
- 移动端：Flutter + Dart
- AI 服务：Python + FastAPI
- 数据库：PostgreSQL + Prisma
